# PI Fork v0.84.2 Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebase the maintained `XialerMoies/pi` fork on upstream `v0.84.2`, retain only the still-required defensive patch, produce a reproducible `@xiamol/pi-coding-agent@0.84.2-xiamol.0` package, and upgrade `my-code-agent` after an explicit publish checkpoint.

**Architecture:** Build a clean synchronization branch from the immutable upstream tag instead of merging 856 historical commits into the old branch. Keep upstream internal packages under `@earendil-works`, publish only the coding-agent wrapper under `@xiamol`, and validate the resulting tarball before touching the application dependency. The old max-thinking patch is not replayed because v0.84.2 already implements and tests that behavior.

**Tech Stack:** Git worktrees, TypeScript, npm workspaces, Vitest, Node test runner, npm tarballs, Electron application integration.
